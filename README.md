# GOD BLOX V2

Versão inicial de uma loja web demonstrativa.

## O que já funciona
- Catálogo e filtros
- Busca
- Carrinho
- Login local demonstrativo
- Pedidos locais demonstrativos
- Layout responsivo
- Persistência no navegador com localStorage

## O que ainda precisa de backend para produção
- Autenticação real
- Banco de dados
- API/server
- Gateway de pagamento
- Webhooks para confirmar pagamentos
- Painel administrativo
- Controle de estoque no servidor
- HTTPS e regras de segurança

## Como testar
Abra `index.html` no navegador.

Para publicar, envie os arquivos para um serviço de hospedagem estática. Para compras reais, o checkout deve chamar um backend e um provedor de pagamento seguro.

Não use este projeto para vender/transferir contas, credenciais, tokens ou itens obtidos de forma ilícita. Verifique os termos de cada plataforma antes de comercializar qualquer item/serviço.
